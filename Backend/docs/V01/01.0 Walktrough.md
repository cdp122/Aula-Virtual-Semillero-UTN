# V1.0 Sistema de Microaulas Virtuales

El presente sistema se realizará para competir en el concurso de facultades FECYT llamado como "semillero" donde se plantea realizar una aplicación PWA con un Backend para sincronización de 2 interfaces distintas. Esta primera versión se plantea como un POC o DEMO. Por ende solo tendrá la base y lo estrictamente necesario para funcionar. 

## Objetivos

- Definir Durante esta primera versión del Backend la BDD, arquitectura, infraestructura tecnológica y los primeros RQ.
- Desarrollar la primera versión del servidor Backend usando las infraestructuras definidas.
- Apoyar con la infraestructura tecnológica necesaria en la carpeta raiz del proyecto. (docker.yaml, package.json, etc)
